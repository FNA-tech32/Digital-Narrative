## ✨ Key Features

- **Responsive & Mobile-First:** Fluid layout engineered with Bootstrap 5, optimized for mobile phones, tablets, laptops, and ultra-wide desktops.
- **Hero Carousel:** Smooth auto-rotating banner highlighting agency capabilities with custom indicator dots and call-to-action buttons.
- **Dynamic Portfolio System:** Filterable multi-category portfolio powered by Isotope layout with interactive GLightbox galleries.
- **Data-Driven Portfolio Details:** Dynamic project detail page that automatically loads images, descriptions, and technology badges based on URL parameters.
- **Interactive Animations:** Subtle scroll animations via AOS (Animate On Scroll) and smooth animated numbers using PureCounter.
- **Touch-Friendly Sliders:** Swiper.js integration for responsive testimonial carousels and multi-image project galleries.
- **PHP Form Processing:** Functional contact form (`forms/contact.php`) and newsletter subscription form (`forms/newsletter.php`) with client-side feedback and validation.
- **SEO & Social Metadata:** Pre-configured Open Graph tags, Twitter Cards, meta descriptions, and semantic headings across every page.
- **Clean Codebase:** Well-commented, organized file architecture following modern web development standards.

## 💻 Technologies & Libraries Used

### Frontend Core
- **HTML5:** Semantic, accessible markup.
- **CSS3:** Custom styles, CSS variables, flexbox, and grid layouts.
- **JavaScript (ES6+):** Vanilla JavaScript modular scripts for DOM manipulation and component lifecycles.
- **Bootstrap 5.3:** Responsive grid system, utilities, buttons, modals, and navbars.
- **Bootstrap Icons:** High-resolution SVG icon set.

### JavaScript Vendors & Plugins
- **[AOS (Animate On Scroll)](https://michalsnik.github.io/aos/):** Scroll-triggered fade, zoom, and slide animations.
- **[Swiper.js](https://swiperjs.com/):** Touch-enabled slider for testimonials and project galleries.
- **[GLightbox](https://biati-digital.github.io/glightbox/):** Lightbox gallery for viewing images and videos.
- **[Isotope](https://isotope.metafizzy.co/):** Filter and sort layout engine for the portfolio grid.
- **[PureCounter](https://github.com/srexi/purecounterjs):** Animated counter for milestones and stats.
- **[Waypoints](http://imakewebthings.com/waypoints/):** Trigger functions when scrolling to elements (used for animated skill bars).
- **[ImagesLoaded](https://imagesloaded.desandro.com/):** Detects when images have finished loading before initializing layouts.

### Backend & Integrations
- **PHP:** Contact form submission and newsletter sign-up processing.
- **Google Maps Embed:** Location map embedded on the contact page.
- **Google Fonts:** Roboto, Poppins, and Raleway font pairings.

## 🚀 Installation & Local Setup

### Option 1: Using PHP Built-In Server (Recommended for Full Form Testing)

Because the contact and newsletter forms utilize PHP handlers, running a local PHP development server allows you to test both frontend and backend functionality:

1. **Verify PHP Installation:**
   ```bash
   php -v
   ```

2. **Navigate to the Project Directory:**
   ```bash
   cd Digital-Narative
   ```

3. **Start the Local PHP Server:**
   ```bash
   php -S localhost:8000
   ```

4. **Access in Your Browser:**
   Open [http://localhost:8000](http://localhost:8000) in any web browser.

---

### Option 2: Using VS Code Live Server / Static Web Server

If you are only working on frontend UI, styling, or JavaScript features:

1. Open the `Digital-Narative` folder in [Visual Studio Code](https://code.visualstudio.com/).
2. Install the **Live Server** extension (by Ritwick Dey).
3. Right-click `index.html` and select **Open with Live Server**.
4. The site will open automatically at `http://127.0.0.1:5500`.

> **Note:** Static servers will render all HTML/CSS/JS components properly. When submitting forms, client-side success feedback modals are triggered automatically by `assets/js/main.js`.

## ✉️ Form Handling & Configuration

The forms in `forms/` handle email notifications:

- **Contact Form (`forms/contact.php`):**
  - Configured to route submissions to:
    ```php
    $receiving_email_address = 'contact@digitalnarative.com';
    // Alternative receiving address: support@digitalnarative.com
    ```
  - Receives `name`, `email`, `subject`, and `message` fields.
  - Optional SMTP credentials can be configured directly inside `forms/contact.php`.

- **Newsletter Subscription (`forms/newsletter.php`):**
  - Configured to route subscription alerts to:
    ```php
    $receiving_email_address = 'newsletter@digitalnarative.com';
    ```
  - Receives user email addresses for subscription lists.

## 🎨 Customization Guide

### 1. Brand Colors & Typography
Custom color schemes and fonts are defined in `assets/css/main.css`. You can adjust the CSS custom properties at the top of the stylesheet to match any branding requirements:
- `--default-color`: Body typography color
- `--heading-color`: Headings and titles
- `--accent-color`: Primary brand accent color
- `--surface-color`: Background surface color
- `--contrast-color`: High contrast text color

### 2. Updating Contact Information
If your contact details change, update the following centralized files:
- **`contact.html`:** The primary contact cards and Google Map coordinates.
- **`service-details.html`:** The quick-help sidebar box.
- **Footer across all pages:** The standard footer contact block.
- **`forms/contact.php`:** The destination inbox address.

### 3. Adding New Portfolio Projects
Dynamic projects in `portfolio-details.html` are configured inside the `portfolioProjects` JavaScript dictionary at the bottom of `portfolio-details.html`. Add your new project key, title, category, client, technologies, and image paths to display them instantly.
